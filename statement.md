# Expense Tracker — Project Statement

## Problem Statement
Managing daily expenses manually can make it difficult to understand where money is being spent and whether spending is within a planned budget. This project provides a simple command-line Expense Tracker that allows users to record expenses, organize them by category, calculate spending summaries, identify the highest expense, and monitor a monthly budget.

## Project Scope
The project is a lightweight, file-based personal expense management system for command-line use. Expense records are stored locally in a text file and loaded when the program starts.

## Target Users
- Students
- Individuals who want to monitor everyday spending
- Beginners learning Python through a practical application

## High-Level Features
1. Add an expense with name, amount, and category.
2. View all stored expenses.
3. Calculate total spending.
4. View category-wise spending.
5. Identify the highest expense.
6. Set a monthly budget.
7. View budget status.
8. Save and load expenses using local file storage.
9. Validate user input.
